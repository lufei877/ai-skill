# /build-fix — 修复构建失败

## 流程

### 1. 获取错误信息
- 运行构建命令，捕获完整错误输出
- 识别第一个错误（后续错误可能是级联的）

### 2. 定位根因
- 从错误信息找到出错的文件和行号
- 检查最近的改动（`git diff`）是否引入了问题
- 查 pitfalls.md 看是否是已知问题

### 3. 精准修复
- 只修复导致构建失败的问题（精准手术）
- 不"顺便"优化或重构
- 修复后立即重新构建验证

### 4. 验证
- 构建通过
- 测试通过（如果有）
- 改动最小化

### 5. 记录（如果是新坑）
- 如果这个构建失败的原因有通用价值 → 追加到 pitfalls.md

## 输出契约

报告复现的错误、已验证根因、最小改动和重新构建或启动结果，保留未解决阻塞。
